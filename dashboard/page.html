Definitions and what this leaves out
Version
A Gambit commit. Bots p49 and p50 ran the same commit, so they are one version; a redeploy with no Gambit change adds games to the same row.
Win rate
Games won out of games won plus lost, as seen by the lobby bot on panelattack.com. Fights and games on the other server are not here.
Plausible range
The 95% Wilson interval for the win rate. Two versions whose lines overlap cannot be told apart yet.
Opponent topped out
Share of the game the opponent had panels or landed garbage in the top row (sampled every half second).
Commit for older bots
For p13 to p27 the commit is the newest Gambit change before the bot started, which can be off by one. From about p28 it is the commit the redeploy was triggered by.
Missing
Run p30 and the unnumbered Ranmaru run saved no log, so their games are not counted. A bot that is still running is counted once it ends.
Source
Snapshot from the saved bot logs of each run. It does not update by itself yet.
