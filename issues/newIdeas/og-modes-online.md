# Bring OG modes online

**Reported:** Bramp, 5/27/26

## Idea

Add original single-player modes (Endless, Puzzle, Time Attack, etc.) to the online experience.

Start with **parallel play**: multiple players each running their own instance of the same mode in a shared room, seeing each other's progress/scores but not directly interacting.

Later: explore true multiplayer variants of these modes.

## Why this is interesting

- Low-risk way to socialize single-player content
- Sets up infrastructure for the [[waiting-room-practice]] idea
