# Waiting room: mini-practice / parallel play

**Reported:** Bramp, 5/27/26

## Idea

While players are sitting in a room waiting for a match to start (or between matches), let them run a lightweight practice session — most likely parallel-play Endless or similar.

## Why

- Dead time in the lobby is wasted; players warm up better by playing
- Naturally pairs with [[og-modes-online]] — same parallel-play substrate

## Notes

- Shouldn't interfere with ready-state or match-start signals
- Probably want it to auto-pause when the host kicks off the real match
